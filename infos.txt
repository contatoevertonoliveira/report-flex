
**Backend (ReportFlex.WebApi)** - ASP.NET Core em .NET 10.0 | .NET Framework 4.8
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Projeto: [ReportFlex.WebApi](file:///c:/Users/EvertonOliveira/Documents/Systems/Csharp/report-flex/ReportFlex.WebApi/ReportFlex.WebApi.csproj)

- **ASP.NET Core (SDK Web)**
  - Vem do próprio SDK: `<Project Sdk="Microsoft.NET.Sdk.Web">` e `TargetFramework>net10.0</TargetFramework>`.
  - Como usamos **Minimal APIs**, você vê tudo concentrado em [Program.cs](file:///c:/Users/EvertonOliveira/Documents/Systems/Csharp/report-flex/ReportFlex.WebApi/Program.cs):
    - Mapeamento de rotas `/api/...`
    - CORS, autenticação, autorização
    - Servir arquivos estáticos do WebApp (SPA)

- **Microsoft.Data.SqlClient (5.2.0)**
  - Pacote: `Microsoft.Data.SqlClient`.
  - Uso principal:
    - Conexão com SQL Server (bases CMS e Logins).
    - Execução de comandos SQL, leitura de dados.
  - Onde aparece:
    - `using Microsoft.Data.SqlClient;` em [Program.cs](file:///c:/Users/EvertonOliveira/Documents/Systems/Csharp/report-flex/ReportFlex.WebApi/Program.cs#L1-L3).
    - Função `GetConn` monta a connection string real/demos, inclusive lendo override de `.env`.
    - Endpoints como `/api/cms/...`, `/api/admin/db-info` e `/api/dev/seed` abrem `SqlConnection` e fazem `SqlCommand`.

- **Microsoft.AspNetCore.Authentication.JwtBearer (8.0.8)**
  - Pacote: `Microsoft.AspNetCore.Authentication.JwtBearer`.
  - Uso principal:
    - Autenticação por **JWT** (token).
    - Validação de token em cima de chave simétrica, emissor, audiência etc.
  - Onde aparece:
    - `using Microsoft.IdentityModel.Tokens;` e `using System.IdentityModel.Tokens.Jwt;` em [Program.cs](file:///c:/Users/EvertonOliveira/Documents/Systems/Csharp/report-flex/ReportFlex.WebApi/Program.cs#L3-L5).
    - Configuração:
      ```csharp
      builder.Services.AddAuthentication().AddJwtBearer(opt =>
      {
          opt.TokenValidationParameters = new TokenValidationParameters
          {
              ValidateIssuer = true,
              ValidateAudience = true,
              ValidateIssuerSigningKey = true,
              ValidIssuer = jwtIssuer,
              ValidAudience = jwtAudience,
              IssuerSigningKey = key
          };
      });
      ```
    - Políticas de autorização:
      - `SuperAdminOnly`
      - `NotCliente` (bloqueia quem tem nível "Cliente" para rotas administrativas, por exemplo `/api/admin/db-info`)

- **DocumentFormat.OpenXml (3.0.2)**
  - Pacote: `DocumentFormat.OpenXml`.
  - Uso principal:
    - Geração/leitura de **planilhas Excel (XLSX)** e outros documentos Office via OpenXML.
  - Onde aparece:
    - `using DocumentFormat.OpenXml;`
    - `using DocumentFormat.OpenXml.Packaging;`
    - `using DocumentFormat.OpenXml.Spreadsheet;`
  - É utilizado em rotas de relatórios relacionados a Excel (não olhamos todos os endpoints aqui, mas o pacote está pronto para gerar arquivos .xlsx em memória).

- **QuestPDF (2024.10.0)**
  - Pacote: `QuestPDF`.
  - Uso principal:
    - Geração de **PDFs** de forma programática.
  - Onde aparece:
    - `using QuestPDF.Fluent;`
    - `using QuestPDF.Infrastructure;`
  - É o motor que monta relatórios PDF para os endpoints `/api/reports/...` (novamente, a base está em [Program.cs](file:///c:/Users/EvertonOliveira/Documents/Systems/Csharp/report-flex/ReportFlex.WebApi/Program.cs) ou em arquivos auxiliares, dependendo da organização).

- **Outras utilidades .NET (sem pacotes externos)**
  - `System.Text.RegularExpressions` → usado para tratar/validar strings, por exemplo processamento de dados e filtros.
  - `System.Security.Claims` → usado junto com JWT para ler claims de nível, client-id etc.
  - Leitura/gravação de `.env`:
    - Implementado manualmente em [Program.cs](file:///c:/Users/EvertonOliveira/Documents/Systems/Csharp/report-flex/ReportFlex.WebApi/Program.cs#L47-L92):
      - `LoadEnv()` e `SaveEnv()` usam `System.IO.File` para persistir:
        - `DB_MODE` (Demo/Real)
        - `DB_CMS_CONN`
        - `DB_LOGINS_CONN`

Resumo do backend:
- **Stack:** ASP.NET Core Minimal API + SQL Server + JWT + geração de PDF/Excel.
- **Persistência de configuração:** `.env` local na pasta da WebApi.
- **Autorização:** baseada em nível do usuário (claims de `nivel`).

**Visão geral de “como estamos trabalhando”**

- **Backend**
  - Minimal API em .NET 10, com rotas bem diretas (sem controllers).
  - SQL Server com `Microsoft.Data.SqlClient`.
  - Configuração dinâmica de banco (Demo/Real) persistida em `.env` da WebApi:
    - `DB_MODE`, `DB_CMS_CONN`, `DB_LOGINS_CONN`.
  - Segurança:
    - JWT para login e autorização.
    - Políticas que separam Cliente de Administrador/SuperAdmin.
  - Geração de relatórios:
    - PDF com QuestPDF.
    - Excel com DocumentFormat.OpenXml.

- **Frontend**
  - SPA React com roteamento interno e proteção de rotas.
  - Bootstrap para layout, sem dependência de JS de terceiros pesado.
  - Comunicação com backend centralizada em `api.ts`, usando fetch e token JWT guardado em `localStorage`.
